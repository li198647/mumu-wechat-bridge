# 微信桥 · 长期记忆

## 这是什么
把「选中的文字 / 剪贴板内容」一键发到电脑版微信的**「文件传输助手」**的桥。
工作区 `E:\workbuddywork\微信桥`，入口 `启动微信桥.bat`（**必须由用户自己双击**）。
定位思路与 QQ 桥（`E:\workbuddywork\一键发到qq`）同源：**不碰客户端 UI，走官方通道**。

## 定稿方案（2026-10-09 拷问定下，10-12 修订）
| 分支 | 定稿 |
|---|---|
| 落点 / 内容 | 只发「文件传输助手」/ 第一版只要文字 |
| 通道 | 官方网页版 `szfilehelper.weixin.qq.com`（`filehelper.…` 会跳 sz）+ Playwright |
| 触发 | 全局热键 **Ctrl+Alt+B**（钩子抢键模式） |
| 取字 | 选中文字优先（注入 Ctrl+C），抓不到退回剪贴板 |
| 形态 | 纯 ctypes 托盘常驻 + 右键菜单（复用 QQ 桥那套写法） |
| 反馈 | 发完在**光标旁**弹提示条 3.5s（只有结果、不显示内容）+ **托盘图标闪烁**（成功 2.5s 绿勾 / 失败 4s 红叉）；成功不弹气泡、失败保留红气泡 |
| **铁律** | 发完**回读校验**，消息真出现才算成功，**绝不假报成功** |

## 关键技术事实（踩过的坑，别重踩）
- ❌ **驱动 PC 微信控件树：实测不可行**。本机微信 **4.1.15.13** 是"哑画布"——
  UIA（RawView / ControlView / FindAll / 焦点元素）和 MSAA（子节点 / 247 点坐标网格）
  **全部问不出任何控件**；顶层窗口类 `Qt51514QWindowIcon`（**不是**社区文档里的 `mmui::MainWindow`）。
  已排除 DPI(96) / 单屏 / "没做 UIA 热激活"（读屏标志本来就是 1）/ 未登录 这些诱因。
  社区"4.1.12.55 可用"的记录**不适用**于新版本。
- ❌ **Hook 注入微信（WeChatFerry 类）**：用户 2026-09-26 明确否掉，**不再推销**。
- ❌ **公众号测试号模板消息**：落点错（发给公众号不是文件传输助手）+ 限流，出局。
- ✅ **网页版控件选择器**：输入框 `textarea.chat-panel__input-container`；
  发送按钮 `a.chat-send__button`（未输入时带 `__disabled`）。
  ⚠️ **必须点真正的 `a` 标签**，点它外层的容器 DIV 无效（曾因此发不出去）。
- ✅ **多行文字**：用整体填充（`fill()` / `insert_text`），**不要逐字敲**——
  敲到换行会直接发出去，消息被切碎。实测三行能作为**一条**气泡发出、换行完整保留。
- ⚠️ **登录态不安分**：网页版 session 与**浏览器进程绑死**，浏览器一关服务端立刻注销，
  连登录时导出的明文 cookie 快照注入也救不回。
  ⇒ 浏览器必须**独立常驻**（`--remote-debugging-port=9222`），桥脚本用 `connect_over_cdp` 连上去；
  这样**桥改代码 / 重启都不影响登录态**，用户不用反复扫码。
  ⇒ 但**长期闲置也会掉**（实测 3 天内掉过一次），**不是永久免扫码**。
- ⚠️ **常驻进程必须用户双击启动**：自动化工具拉起的进程会随会话被连带清理，
  连 `CREATE_BREAKAWAY_FROM_JOB` 都无效（已实测）。
- ⚠️ **快捷键注入的坑（10-12 真根因）**：热键触发瞬间手指还按着 Ctrl/Alt，
  此时注入 `Ctrl+C` 系统收到的是 **Ctrl+Alt+C** → 复制失败（退回旧剪贴板）
  + 误触发 **QQ 长截图**。修法：注入前用 `GetAsyncKeyState` 等修饰键松开，超时强制 KEYUP。
- ⚠️ **QQ 用低级键盘钩子抢键**，`RegisterHotKey` 抢不过、也**测不出**（详见全局记忆）。
  桥改用 `WH_KEYBOARD_LL` 吞键后，QQ 收不到按键，不再弹。
- ⚠️ **Windows 没有「让托盘图标闪烁」的 API**（`Shell_NotifyIcon` 只有 ADD/MODIFY/DELETE）。
  只能 `SetTimer` + 反复 `NIM_MODIFY` 在两个图标间切换来伪造。
  定时器必须装在**有消息循环的线程**（这里是托盘线程），否则收不到 `WM_TIMER`。
  闪烁图标在 16px 下必须**大面积色块不同**才看得清（绿底白勾 vs 绿底白气泡，不是"加个小角标"）。
- ⚠️ **ctypes 三个必踩的坑（本轮全踩了一遍）**：
  ① `DrawTextW` 在 **user32** 不在 gdi32；② `GetDC` / `GetModuleHandleW` 不声明 `restype`
  会被默认 `c_int` 截断 64 位句柄；③ `"...%d" % time.time_ns() % 10**9` 的取模会
  先绑定到格式化结果（对字符串取模）→ `TypeError`，必须加括号。
  ⇒ 教训：**这类异常绝不能被空 `except` 静默吞掉**，现在失败会写 `self.err` 并打到 stderr。

## 运行 / 排障
- 启动：双击 `启动微信桥.bat`；停机：**托盘右键 → 退出微信桥**（❌ 别在任务管理器杀 chrome）。
- 状态自检：`tools/check_state.py`（只读：连 9222 报 URL/标题/是否已登录）。
- 日志：`tools/wx_bridge.log`（每步都记，排障先看它）。
- 托盘右键菜单：发送剪贴板 / **预览提示效果**（不真发消息，先看观感） / **热键检测** /
  显示日志 / 隐藏窗口 / 打开文件夹 / **重启微信桥** / 退出。
- 关键文件：`tools/wx_bridge.py`（主程序）、`wx_tray.py`（托盘 + 钩子热键 + **图标闪烁**）、
  `wx_send.py`（发送核心）、`wx_toast.py`（**光标旁提示条**，自绘浮窗）、
  `make_icons.py`（生成 `wx.ico` / `wx_ok.ico` / `wx_err.ico`）、
  `hotkey_scan.py`（热键探测）、`hotkey_test.py`（热键真机测试）、
  `flash_test.py`（**闪烁实证**：记录每次换图标 + 抓托盘截图）、`hook_probe*.py`（抢键实验）。
